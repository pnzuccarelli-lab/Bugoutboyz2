# Bug Out Boyz

A map dashboard that ranks US properties as potential bug-out sites: walking distance to fresh
water, distance from cities, local population density, existing shelter, a town for resupply,
and a public-record path to buying the land.

This repository holds only the published site: `index.html` and its data file `scout-data.js`.
It contains no owner names. The files are generated by `python -m scout public` in
`pnzuccarelli-lab/metal-scout---private`; regenerate and replace them instead of editing by hand.

To serve it with GitHub Pages: Settings → Pages → Deploy from a branch → `main`, `/ (root)`.

Every site belongs to someone until it is bought. This is an acquisition shortlist built from
public lists that may be out of date, not permission to enter or occupy land.
