# BuggedOut USA

Survival site location engine for when SHTF.

A map dashboard that ranks US properties as potential bug-out sites: fresh water within walking
distance, distance from cities and interstates, natural and man-made hazards, a small town and a
hospital within reach, growing season and rainfall, existing shelter, state law and taxes, public
land next door, and a public-record path to buying the land. Each visitor sets their own starting
point, and the site can be saved to a phone for use without signal.

This repository holds only the published site. It contains no owner names. The files are generated
by `python -m scout public` in `pnzuccarelli-lab/metal-scout---private`; regenerate and replace
them instead of editing by hand.

Served with GitHub Pages from `main`, `/ (root)`.

Every site belongs to someone until it is bought. This is an acquisition shortlist built from
public lists that may be out of date, not permission to enter or occupy land.
